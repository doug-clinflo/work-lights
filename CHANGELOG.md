# Changelog

## v0.1 — first public preview

- Local room creation, selection, renaming, deletion, bulb assignment and reassignment.
- Selected-room activity-aware light restoration with idle grace, timed hold and Pause.
- Scene favourites, relative dimming and brightness presets with result checks.
- Explicit discovery and persistent device identities to recover address changes.
- Empty, paused first-run setup; private configuration created locally.
- Universal macOS 13+ build scripts, offline checks, CI, MIT licence and documented limitations.

Private prototype numbering is separate from this public release series. Multi-room hardware verification and remote CI results are pending.
